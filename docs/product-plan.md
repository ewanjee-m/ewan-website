# 제품 계획

## 목표

방문자가 남성 또는 여성 플레이어 캐릭터를 선택하고 일본 마을을 직접 탐색하며 포트폴리오 내용을 발견하게 한다. 승인된 마을 원화의 구도와 캐릭터 정체성을 유지하면서 데스크톱과 모바일에서 같은 장소, 이동, 지도와 안내 기능을 제공한다.

## 사용자 흐름

1. 한국어, 일본어, 영어 중 하나를 선택한다.
2. 시작 화면에서 `START`를 누른다.
3. 남성 또는 여성 캐릭터 카드를 선택하고 월드에 들어간다.
4. 방향키 또는 화면 왼쪽 이동 조작으로 공항, 도쿄, 규카츠, 벚꽃 수로, 하나비 장소를 탐색한다.
5. `Space` 또는 점프 버튼으로 점프한다.
6. 미니맵에서 현재 위치, 방향, 장소와 연결 경로를 확인한다.
7. 전체 지도에서 장소를 누르면 해당 도착점으로 한 번에 이동한다.
8. 길 안내에서 현재 날씨 또는 오늘의 포춘을 선택해 목적지와 방향을 추천받는다.
9. 포트폴리오 목록에서 항목을 연다.

길 안내는 이동과 독립적이다. 추천이 있어도 방문자는 다른 방향으로 걸을 수 있고, 전체 지도에서 다섯 장소 중 하나를 선택할 수 있다.

## 화면 기준

| 환경 | 뷰포트 | 월드 표시 영역 |
| --- | --- | --- |
| 데스크톱 | `1440x900` | `(0,0,1440,900)` |
| 모바일 | `390x844` | `(0,64,390,780)` |

모바일 상단 `64px`은 언어와 UI가 겹치지 않도록 월드 표시에서 제외한다. 시작·선택·월드 단계는 화면 전환 때 스크롤 위치를 초기화한다.

## 렌더러

활성 경로는 `ExperienceShell -> WorldView -> FlatWorldCanvas`다.

`FlatWorldCanvas`는 승인 원화 기준 Canvas 2D 렌더러다. `1817x866` 원화를 다음 요소의 공통 등록 기준으로 사용한다.

- 배경
- 플레이어 발 위치와 방향별 WebP 프레임
- 접촉 그림자
- 구역별 잘라 낸 전경
- 카메라 표시 창
- 미니맵과 전체 지도
- 장소 도착점과 이동 경로

카메라는 입체 장면을 회전하지 않는다. 플레이어의 논리 위치를 원화 좌표로 투영하고, 해당 구역의 주요 장소가 프레임에 남도록 원화 안의 표시 창을 이동한다. 보통 이동에서는 화면 변화량을 제한하고, 전체 지도 이동·위치 초기화·화면 크기 변경에서는 등록 상태를 한 번에 다시 맞춘다.

Canvas 2D는 WebGL 또는 WebGL2 컨텍스트를 만들지 않는다. GPU 메모리 검증은 `0`으로 기록하지 않고 `NOT_APPLICABLE`로 기록한다.

## 월드

논리 경계는 `x=-36~36`, `z=-36~36`이다. 다섯 장소, 도착점, 연결 경로, 구조물 차단 영역, 운하와 다리를 하나의 데이터 모델로 관리한다.

- 공항은 시작 장소다.
- 도쿄, 규카츠, 벚꽃 수로와 하나비는 등록된 경로로 연결된다.
- 운하는 다리 경로에서만 건널 수 있다.
- 구조물과 물의 차단 영역 밖에서는 이동할 수 있다.
- 카메라, 미니맵, 전체 지도와 길 안내는 같은 위치 스냅샷을 읽는다.

전체 지도 이동은 입력 큐를 거쳐 한 프레임에서 처리한다. 목적지 좌표, 바라보는 방향, 구역, 카메라 등록, 지도와 안내가 읽는 탐색 스냅샷을 같은 리비전으로 갱신한다.

## 캐릭터

남성과 여성은 외형만 다르고 이동·충돌·점프 능력은 같다. 런타임 자산은 정면, 후면, 측면 방향과 달리기 두 프레임을 포함한 `768x1152` WebP다.

- 정면과 후면은 각각의 프레임을 사용한다.
- 왼쪽 측면은 오른쪽 프레임을 가로 반전한다.
- 이동 중에는 두 달리기 프레임을 교대한다.
- 점프 중에는 현재 방향과 동작 프레임을 유지하고 캐릭터의 화면 높이와 접촉 그림자를 분리한다.
- 프레임마다 투명 여백 안의 발 위치를 보정해 접지점을 맞춘다.
- 전경 마스크가 난간, 나무, 건물 가장자리 뒤로 지나가는 효과를 만든다.

## 인터페이스

- 시작 화면은 승인 배경, 어두운 그라데이션, 언어 선택과 시작 카드로 구성한다.
- 캐릭터 선택은 `320x525` 카드 두 장을 사용하며 모바일에서는 한 열로 배치한다.
- 월드에서는 이동, 점프, 시작 위치 복귀, 길 안내, 포트폴리오, 미니맵과 전체 지도를 제공한다.
- 전체 지도는 모달 대화상자이며 키보드 초점을 내부에 유지하고 닫을 때 열기 버튼으로 되돌린다.
- 길 안내, 포트폴리오 대화상자 또는 전체 지도가 열리면 미니맵을 숨겨 겹침을 줄인다.

## 길 안내와 개인정보

길 안내 요청은 `weather`와 `fortune`만 허용한다. 서버 응답의 목적지, 테마와 근거를 허용 목록으로 검증한다.

- 날씨는 도쿄 고정 좌표와 `Asia/Tokyo` 시각을 사용한다.
- 현재 장소는 추천 후보에서 제외한다.
- API 또는 날씨 요청이 실패하면 같은 입력으로 검증된 로컬 추천을 만든다.
- 이름, 이메일, 생년월일, 성별, 방문자 위치 권한과 자유 입력을 요구하지 않는다.
- `OPENAI_API_KEY`는 서버 환경에서만 읽는다.
