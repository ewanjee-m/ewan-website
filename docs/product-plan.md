# 제품 계획

## 목표

방문자가 남성 또는 여성 플레이어 캐릭터를 선택하고 하나의 연속된 일본 축제 3D 마을을 직접 탐색하며 포트폴리오 내용을 발견하게 한다.

## 사용자 흐름

1. 언어를 고르고 시작한다.
2. 남성 또는 여성 캐릭터를 선택한다.
3. 공항에서 월드에 입장한다.
4. 키보드 또는 터치로 도쿄, 규카츠, 벚꽃과 하나비까지 이동한다.
5. 카메라를 회전하고 점프하며 지도에서 현재 위치를 확인한다.
6. 가까운 장소 또는 NPC와 상호작용한다.
7. 날씨 또는 포춘 길 안내를 선택한다.

전체 지도는 장소 설명을 살펴보는 용도다. 플레이어 이동은 직접 입력으로만 수행하고 시작 위치 복귀는 별도 초기화 조작으로만 수행한다.

## 렌더러

`SeamlessWorldCanvas`는 하나의 지속되는 WebGL 3D RPG 월드 렌더러다.

```text
ExperienceShell
→ WorldView
→ SeamlessWorldCanvas
→ WorldRuntime + RpgTownScene + RpgPlayerActor + ChaseOrbitCamera3d
```

월드 입장 뒤 Canvas는 다시 만들어지지 않는다. 구역 전환은 같은 장면 안에서 이루어지며 경계 통과 중 새 자산 요청을 시작하지 않는다.

## 완료 조건

- 남성·여성 GLB가 선택대로 나타난다.
- 다섯 장소를 실제 입력으로 순서대로 통과한다.
- 운하는 차단되고 다리는 통과된다.
- 지도 위치가 같은 리비전으로 `100ms` 안에 갱신된다.
- 카메라 충돌, 안전 영역과 자동 복귀 진단이 통과한다.
- 개별 자산 실패가 URL이나 스택 없이 정리된 오류로 남고 나머지 월드는 계속 동작한다.
- 단위, 타입, 린트, 빌드, E2E, 시각 도구 자체 검증과 성능 검증이 통과한다.
- 데스크톱과 모바일 합계 20개 시각 캡처는 별도 검토 뒤에만 최종 `PASS`가 된다.
