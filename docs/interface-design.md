# 인터페이스 디자인

## 화면 단계

`ExperienceShell`은 `start`, `select`, `world` 세 단계를 관리한다. 단계가 바뀔 때 문서와 셸의 스크롤 위치를 맨 위로 돌린다.

언어 선택은 모든 단계의 오른쪽 위에 표시한다. 한국어, 일본어, 영어 버튼은 `aria-pressed`로 현재 언어를 알리고, 선택한 언어는 브라우저 저장소와 경로에 반영한다.

## 시작 화면

시작 화면은 다음 DOM 계층으로 구성한다.

1. `/assets/world/world-environment-concept.png` 배경 이미지
2. 위에서 아래로 어두워지는 반투명 그라데이션
3. 브랜드, 제목, 소개, `START` 버튼과 조작 설명을 담은 카드
4. 언어 선택

배경은 화면 전체를 채우고 가운데를 기준으로 잘라 표시한다. 카드는 반투명 남색 배경, 금색 테두리, 잘린 모서리와 흐림 효과를 사용한다.

## 캐릭터 선택

선택 화면은 남성·여성 버튼 카드를 제공한다.

- 각 카드의 기준 크기는 `320x525`다.
- 데스크톱 두 카드 사이 간격은 `46px`이다.
- 카드 이미지는 원본 `1024x1536` PNG를 높이 `430px`로 맞춰 표시한다.
- 선택 상태는 `aria-pressed`, 금색 `3px` 테두리와 상태 문구로 함께 표시한다.
- 캐릭터를 고르기 전에는 월드 입장 버튼을 비활성화한다.
- 화면 폭 `820px` 이하에서는 카드를 한 열로 배치한다.

카드의 남성·여성 선택은 외형만 바꾸며 이동, 점프, 충돌과 볼 수 있는 콘텐츠는 바꾸지 않는다.

## 월드 화면

월드 루트는 화면 전체를 채우고 스크롤을 막는다. `FlatWorldCanvas`가 `(0,0)`부터 렌더러를 배치하고, `WorldView`가 다음 조작을 위에 겹친다.

- 왼쪽 위: 길 안내 열기
- 모바일 왼쪽 아래: 이동 조작
- 오른쪽: 시작 위치 복귀, 전체 지도 열기
- 오른쪽 아래: 점프
- 미니맵
- 포트폴리오 목록과 대화상자

카메라 회전용 드래그 영역과 카메라 초기화 버튼은 활성 인터페이스에 없다. 위치 복귀 버튼은 플레이어를 시작 위치로 되돌리는 기능이며 카메라 회전 초기화가 아니다.

## 모바일 안전 배치

검증 기준은 `390x844`다. Canvas 2D 월드의 안전 프레임은 `(0,64,390,780)`이며 상단 `64px`을 언어와 상단 UI 영역으로 둔다.

- 이동 조작은 왼쪽 아래에 `7.5rem` 원형으로 배치한다.
- 점프 버튼은 오른쪽 아래에 `4rem` 원형으로 배치한다.
- 길 안내 패널은 상단 UI와 오른쪽 조작 영역을 피해 배치하고 내부만 세로 스크롤한다.
- 포트폴리오 목록은 모바일에서 버튼으로 열고 닫는다.
- 미니맵은 모바일에서 접힌 버튼 또는 펼친 지도로 표시한다.
- 전체 지도 장소 버튼은 최소 `76x44px` 터치 영역을 사용한다.

## 미니맵

미니맵은 다음 정보를 표시한다.

- 승인 원화 기준 지형과 해안선
- 다섯 장소
- 연결 경로와 다리
- 추천 목적지
- 플레이어 위치와 진행 방향
- 북쪽 표시

접기·펼치기 버튼은 `aria-expanded`를 제공한다. 길 안내 패널, 포트폴리오 대화상자 또는 전체 지도가 열리면 미니맵을 숨긴다. 해당 UI를 닫으면 같은 탐색 상태로 다시 표시한다.

## 전체 지도

전체 지도는 `role="dialog"`와 `aria-modal="true"`를 가진 대화상자다.

- 제목과 현재 장소를 표시한다.
- 다섯 장소에 이동 버튼을 제공한다.
- 현재 장소 버튼은 `aria-current`로 표시한다.
- `Tab`과 `Shift+Tab` 초점을 대화상자 안에서 순환시킨다.
- `Escape` 또는 닫기 버튼으로 닫는다.
- 닫힌 뒤 초점을 전체 지도 열기 버튼으로 되돌린다.
- `M` 키로 열고 닫을 수 있으며 입력 요소를 편집할 때는 단축키를 처리하지 않는다.

장소 버튼을 누르면 전체 지도를 닫고 목적지 이동을 큐에 넣는다. 다음 렌더 프레임에서 위치, 방향, 현재 장소와 지도 표시가 함께 갱신된다.

## 길 안내 패널

길 안내는 닫힌 버튼, 선택, 요청 중, 결과 상태를 가진다.

- 선택 상태에서 현재 날씨와 오늘의 포춘 버튼을 제공한다.
- 요청 중에는 진행 표시와 취소 버튼을 제공한다.
- 결과 상태에서 장소, 방향, 테마와 데이터 설명을 보여 준다.
- 닫기와 `Escape`를 지원한다.
- 상태 변화는 `role="status"`와 `aria-live="polite"` 영역으로 알린다.
- 패널의 포인터 입력은 월드 이동으로 전달하지 않는다.

길 안내는 추천만 갱신한다. 플레이어 이동 조작과 전체 지도 기능은 별도로 유지한다.

## 키보드와 포커스

- 방향키: 이동
- `Space`: 점프
- `M`: 전체 지도 열기·닫기
- `Escape`: 열린 길 안내 또는 전체 지도 닫기
- 모든 버튼과 링크: 눈에 보이는 `3px` 초점 표시

텍스트 입력, 선택 요소 또는 편집 가능한 요소에 초점이 있을 때 전체 지도 단축키를 가로채지 않는다.
