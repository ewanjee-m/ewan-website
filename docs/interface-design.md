# 인터페이스 디자인

## 화면 단계

`ExperienceShell`은 `start`, `select`, `world` 단계를 관리한다. 시작과 선택 화면은 `/assets/world/world-environment-concept.png`를 참고 이미지로 사용한다. 월드에 들어간 뒤 활성 Canvas와 지도는 이 이미지를 요청하거나 렌더링하지 않는다.

## 캐릭터 선택

- 남성·여성 카드와 앞모습 참고 PNG를 제공한다.
- 선택 상태는 `aria-pressed`, 테두리와 상태 문구로 표시한다.
- 캐릭터 선택 전에는 월드 입장 버튼을 비활성화한다.
- 선택은 외형만 바꾸고 이동, 충돌과 콘텐츠 범위를 바꾸지 않는다.

## 월드 UI

`SeamlessWorldCanvas`가 화면 전체 WebGL 장면을 렌더링하고 `WorldView`가 다음 조작을 겹친다.

- 길 안내와 포트폴리오
- 모바일 왼쪽 이동 조이스틱
- 오른쪽의 시작 위치 복귀, 전체 지도, 점프
- 마우스·터치 카메라 드래그 영역
- 미니맵과 전체 지도
- 가까운 대상 상호작용 버튼

데스크톱은 `1440x900`, 모바일은 `390x844`를 기준으로 검증한다. 조작은 화면 안에 남고 지도·길 안내·포트폴리오가 열리면 겹치는 UI를 숨긴다.

## 입력 차단

- 전체 지도는 `data-world-input-block="true"` 대화상자다.
- 지도에서 이동, 점프, 초기화, 상호작용과 카메라 조작을 입력 큐에 넣지 않는다.
- 상호작용 대화상자가 열리면 현재 입력을 비우고 런타임 진행을 잠근다.
- `Escape`는 지도 또는 상호작용을 닫고 원래 조작으로 초점을 돌린다.

## 지도

미니맵과 전체 지도는 `RpgMapTerrain`과 같은 탐색 스냅샷을 사용한다. 플레이어 마커는 `data-navigation-revision`과 `data-anchor-reference`를 제공한다. 전체 지도의 다섯 장소 버튼은 설명을 선택할 뿐 플레이어를 이동시키지 않는다.

## 접근성

- 모든 조작은 명시적 접근성 이름을 가진다.
- 지도와 포트폴리오는 모달 대화상자와 초점 고정을 사용한다.
- 키보드 `M`으로 지도를 열고 닫을 수 있다.
- 현재 위치, 방향과 선택 상태는 시각 표현 외 데이터 속성과 ARIA 상태로도 제공한다.
