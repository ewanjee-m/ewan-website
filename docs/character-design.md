# 플레이어 캐릭터 디자인

## 역할

방문자는 남성 또는 여성 플레이어 캐릭터 중 하나를 선택한다. 두 캐릭터는 외형만 다르며 이동 속도, 점프, 충돌, 지도 이동, 길 안내와 포트폴리오 접근은 같다.

선택 화면은 `1024x1536` PNG를 사용한다. 월드는 같은 캐릭터 정체성을 유지하는 `768x1152` WebP 런타임 스프라이트를 Canvas 2D에 그린다.

## 런타임 프레임

각 캐릭터의 런타임 목록은 여덟 프레임으로 구성한다.

| 방향 | 대기 | 달리기 |
| --- | --- | --- |
| 정면 | 정면 대기 | 정면 `A`, `B` |
| 후면 | 후면 대기 | 후면 `A`, `B` |
| 측면 | 오른쪽 측면 `A` | 오른쪽 측면 `A`, `B` |

측면 대기는 측면 달리기 첫 프레임을 함께 사용한다. 왼쪽을 향할 때는 오른쪽 측면 자산을 Canvas 2D에서 가로 반전한다. 정면과 후면 자산은 반전하지 않는다.

모든 런타임 자산은 투명 배경의 WebP이며 파일 경로는 `/assets/characters/runtime/` 아래에 있다.

## 동작

- 멈춰 있으면 현재 방향의 대기 프레임을 사용한다.
- 이동하면 진행 방향을 정면, 후면, 측면 중 하나로 선택하고 두 달리기 프레임을 교대한다.
- 점프하면 현재 방향과 선택된 프레임을 유지하면서 플레이어 높이를 지면에서 분리한다.
- 측면 입력이 왼쪽이면 `scaleX=-1`, 오른쪽이면 `scaleX=1`로 그린다.
- 이동 방향이 바뀌어도 남성·여성 자산과 프레임 목록은 바뀌지 않는다.

점프는 별도 3D 뼈대 동작이 아니다. Canvas 2D 스프라이트의 화면 위치, 동작 상태와 접촉 그림자 비율로 표현한다.

## 이미지 안의 발 접지

각 PNG 원본은 발 아래에 서로 다른 투명 여백을 가진다. `CharacterAssets.ts`는 프레임마다 원본 높이 `1536`을 기준으로 발 오프셋을 기록한다. WebP로 바뀐 뒤에도 이 비율을 유지한다.

`RpgPlayerCharacterSprite`는 다음 순서로 접지한다.

1. 논리 월드 위치를 `1817x866` 원화의 기준 발 픽셀로 투영한다.
2. 카메라 표시 창을 적용해 화면의 발 좌표를 구한다.
3. 프레임의 발 오프셋만큼 투명 여백을 보정한다.
4. 스프라이트의 보이는 발이 화면 발 좌표에 닿도록 위쪽으로 그린다.

이 방식은 프레임마다 투명 여백이 달라도 발이 튀거나 공중에 뜨는 현상을 줄인다.

## 표시 크기

월드의 CSS 표시 높이는 카메라 프로필과 장소에 따라 정한다.

| 프로필 | 장소 | 높이 |
| --- | --- | --- |
| 데스크톱 | 공항 | `144px` |
| 데스크톱 | 도쿄 | `128px` |
| 데스크톱 | 규카츠 | `138px` |
| 데스크톱 | 벚꽃 수로 | `144px` |
| 데스크톱 | 하나비 | `128px` |
| 모바일 | 모든 장소 | `122px` |

스프라이트의 폭은 런타임 비율 `2:3`으로 계산한다. Canvas의 실제 픽셀 크기는 기기 픽셀 비율을 최대 `2`까지 적용하지만 CSS 표시 크기는 위 값으로 유지한다.

## 접촉 그림자

접촉 그림자는 플레이어 Canvas 아래에 놓인 타원이다.

- 모바일 기준 크기: `48x14px`
- 데스크톱 기준 크기: 장소에 따라 폭 `50~58px`, 높이 `14~15px`
- 발 아래 오프셋: `4px`

달리기와 점프 상태에 따라 폭과 불투명도를 조절한다. 점프 중에도 그림자는 지면의 발 위치에 남아 캐릭터 높이를 읽을 수 있게 한다.

## 전경과 깊이

플레이어는 승인 원화의 깊이 구간에 따라 전경 뒤로 들어갈 수 있다. 공항 보호대, 도쿄 거리 가장자리, 규카츠 건물, 벚꽃 수로 난간, 하나비 난간과 기둥을 원화에서 잘라 플레이어 위에 겹친다.

플레이어, 그림자와 전경은 같은 탐색 리비전과 원화 변환을 사용한다. 전체 지도 이동이나 화면 크기 변경에서도 세 요소를 같은 프레임에 다시 맞춘다.

## 선택 화면과 월드의 일치

- 선택 화면과 월드의 캐릭터 ID는 `male`, `female`로 같다.
- 선택 화면의 앞모습과 월드의 정면 대기 프레임은 같은 원본 정체성을 사용한다.
- 선택한 캐릭터는 브라우저 저장소에 기록한다.
- 성별 선택은 이동, 지도, 안내 또는 콘텐츠 범위를 바꾸지 않는다.

## 검증 기준

- 남성·여성 런타임 목록에 정면, 후면, 측면과 두 달리기 프레임이 모두 있다.
- 런타임 파일은 `768x1152` WebP다.
- 왼쪽 측면만 가로 반전하고 정면·후면은 반전하지 않는다.
- 현재 프레임의 발 오프셋이 Canvas 배치에 적용된다.
- 대기, 달리기, 점프 상태가 렌더러 텔레메트리에 기록된다.
- 플레이어, 접촉 그림자와 전경의 등록 리비전이 일치한다.
